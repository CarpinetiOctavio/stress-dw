# Fact table `fact_response`

## Columns

| Column | Type | Constraint | Meaning |
|--------|------|------------|---------|
| `response_id` | INT | primary key; not generated by the fact load | identifier of the staged record the row was built from (lineage; not a measure) |
| `time_id` | INT | NOT NULL, foreign key to [`dim_time`](dimensions.md#dim_time) | |
| `gender_id` | INT | NOT NULL, foreign key to [`dim_gender`](dimensions.md#dim_gender-dim_family_history-dim_occupation) | |
| `family_history_id` | INT | NOT NULL, foreign key to [`dim_family_history`](dimensions.md#dim_gender-dim_family_history-dim_occupation) | |
| `occupation_id` | INT | NOT NULL, foreign key to [`dim_occupation`](dimensions.md#dim_gender-dim_family_history-dim_occupation) | |
| `country_id` | INT | NOT NULL, foreign key to [`dim_country`](dimensions.md#dim_country) | |
| `isolation_id` | INT | NOT NULL, foreign key to [`dim_isolation`](dimensions.md#dim_isolation) | |
| `access_id` | INT | NOT NULL, foreign key to [`dim_access`](dimensions.md#dim_access) | |
| `symptoms_id` | INT | NOT NULL, foreign key to [`dim_symptoms`](dimensions.md#dim_symptoms) | |
| `treatment` | VARCHAR(3) | NOT NULL; `Yes` or `No` | lifetime treatment-seeking, raw categorical value |

Foreign keys are enforced by the database (InnoDB). The table has no other column.

## Grain

One row per staged record, that is, one row per survey response. `treatment` is the single measure; it is stored as the raw categorical value, and every count or rate over it is computed at query time ([nothing derived is stored](definitions.md#model-conventions)).

## Invariants

* **I1.** `COUNT(*)` of `fact_response` equals `COUNT(*)` of staging, and the set of `response_id` values equals the set of staging identifiers.
* **I2.** Joining staging to the eight dimensions on their [natural keys](definitions.md#dimension-grain-rule) returns exactly one dimension row per staged record and dimension; the join multiplies no rows.
* **I3.** Every foreign key resolves to a dimension row.
* **I4.** `treatment` holds only `Yes` or `No`.
