# Explainers

The documentation has three layers ([ADR-0015](../decisions/0015-layer-the-documentation-readme-explainers-records.md)). The [README](../../README.md) states each point in plain terms. An explainer develops one point directly, on one page, and links the versioned record behind every claim. The records (specification, decision records, audit documents) are the proof. A [concept transfer](../concept-transfers/README.md) explains by analogy instead; an explainer explains the case itself.

An explainer restates no rule and no count; it links them ([concept homes](../concept-homes.md)). Its figures are embedded from their home documents.

| [Why and how](why-and-how.md) | Why the warehouse was built on a file whose outputs cannot be used as findings |
| [Fan-out](fan-out.md) | The first error of the course version, and the rule and checks that prevent it |
| [Average of rates](average-of-rates.md) | The second error, and the rule and checks that prevent it |

| [How it was evaluated](how-it-was-evaluated.md) | How the evaluation was fixed in advance, and where the method overreached |
