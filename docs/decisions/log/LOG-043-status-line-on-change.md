# Add a new dated status line when the state of an open item changes

## Decision

When the state of an item changes after its status line ([LOG-038](LOG-038-status-lines-for-open-items.md)), a new dated status line is added at the end of the section, below the earlier ones; earlier status lines stay as written. [LOG-010](LOG-010-concept-home-map.md) receives one for the home of the reading rule.

## Linked findings

None.

## Options considered

* (a) A new status line.
* (b) The existing line edited in place.
* (c) No change.

## Option chosen

(a).

## Reasons

* A status line states what happened and when; a later state is a later line.

## Reasons for each rejected option

* (b): it erases a recorded state, against the reasoning of LOG-038.
* (c): LOG-010 keeps stating as open a home that [LOG-039](LOG-039-reading-rule.md) set.

## Open, and where it goes

None.
