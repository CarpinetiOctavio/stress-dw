# Allow sentence-initial See as a cross-reference convention

## Decision

A sentence that begins "See …" is a cross-reference convention, not an instruction addressed to a reader. The "Allowed" list of [writing conventions, rule 2](../../writing-conventions.md#2-voice) states it in one line. Existing uses stay (DC-69).

## Linked findings

Item N10 of the [documentation-currency register](../../audit/documentation-currency.md#8-decide-items); finding DC-69.

## Options considered

* (N10a) Allowed, and stated in rule 2.
* (N10b) Allowed, without a statement.
* (N10c) The uses rewritten.

## Option chosen

(N10a). PR group: none carried by DC-69; the plan of stage 3 assigns it.

## Reasons

* One line in the rule settles about forty uses in nineteen files and keeps them from being flagged again.

## Reasons for each rejected option

* (N10b): the question would come back at the next review.
* (N10c): it changes nineteen files for no change of meaning.

## Open, and where it goes

* The wording of the line in rule 2: the plan of stage 3.
