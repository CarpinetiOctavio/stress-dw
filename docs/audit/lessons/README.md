# Method lessons

Lessons drawn from the project's own work: what went wrong or nearly went wrong in method, and the rule or check adopted so it does not recur. They are grouped by theme, not by phase, since the same lesson can recur in any phase. The decisions that adopted a rule are in the [decision log](../../decisions/log/README.md).

## Format

Each lesson is a section of its theme file, headed `LSN-NNN — short title` (three digits, never reused), with four parts:

1. **What happened.**
2. **How it was detected.**
3. **Rule.** The rule or check that follows, stated in one sentence; or, where a decision adopted the rule, `Rule: see LOG-NNN`, so the rule has one home.
4. **Pointers.** The decisions, findings or sections involved, by ID.
